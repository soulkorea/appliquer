# Appliquer Output Specification

> Version: Brain v0.1.0
> Status: Active

## Purpose

The Output Specification defines the standard structure and presentation of every recommendation generated by Appliquer.

Consistency builds trust.

Every opportunity evaluation should follow this format unless a future capability explicitly defines an alternative.
