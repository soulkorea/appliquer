# Appliquer Architecture

```
Vision
    ↓
Brain
    ↓
Capabilities
    ↓
Implementation
```

## Brain

The Brain contains the reasoning engine.

- Constitution
- Decision Engine
- Evaluation Rubric
- Communication Style
- Output Specification

## Capabilities

The Brain powers independent capabilities.

- Opportunity Evaluation
- Resume Tailoring
- Company Research
- Interview Preparation
- Career Memory

Each capability owns its own implementation issues.

## Validation

Every capability must be validated using real-world job opportunities before being considered complete.
